# Ratnalyzer

Análise de sessões do MED-PC no navegador. Abre o arquivo bruto, identifica os eventos e
apresenta linha do tempo, estatísticas, análises de tempo entre eventos e regressão
linear. Nenhum dado sai da máquina.

```bash
npm install
npm run dev
```
